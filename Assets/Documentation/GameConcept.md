# 🔥 COST FIRE - Game Design Document

## Overview
Cost Fire is a professional 6v6 team-based first-person shooter featuring intense tactical gameplay in an abandoned factory setting.

## Core Mechanics

### 1. Player System
- **Dynamic Names**: Players get temporary names each match (Player_1, Player_2, etc.)
- **Health System**: 100 HP starting health
- **Movement**: Smooth WASD + Mouse controls
- **Jump**: Space to jump

### 2. Weapon System
- **AR-15**: Primary weapon
  - Damage: 25 per hit
  - Fire Rate: 0.1s
  - Ammo: 30/mag
  - Reload: 2.5s
  
- **Additional Weapons** (Future):
  - Sniper Rifle
  - SMG
  - Shotgun
  - Pistol

### 3. Team System
- **Red Team vs Blue Team**
- **6 Players per Team**
- **Team Skins/Uniforms**: Different appearance for each team
- **Team Spawn Zones**: Designated spawn areas for each team

### 4. Map Design - Abandoned Factory
- **Size**: 200x50x200 units
- **Features**:
  - Industrial containers for cover
  - Metal structures and scaffolding
  - Multiple sight lines and chokepoints
  - Destructible objects
  - Cover points strategically placed

### 5. Mission System
- Players are assigned random missions during matches
- Mission completion grants bonus rewards
- Mission locations marked on map

### 6. Victory Conditions
- **Team Elimination**: Eliminate all enemy team members
- **Time Limit**: 5 minutes per match
- **Objectives**: Complete team missions (future enhancement)

## Animations

- Reload animation (2.5 seconds)
- Movement animations
- Death animation
- Damage reaction
