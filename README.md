# 🔥 Cost Fire - Team-Based Shooter Game

## Game Overview
**Cost Fire** is a professional-grade 6v6 team-based first-person shooter game built with Unity and C#.

### Game Features
- **6v6 Team Gameplay** - Two opposing teams battling in intense matches
- **Abandoned Factory Map** - Large industrial area with containers and hiding spots
- **Multiple Weapons** - Choose from various guns with different stats
- **Realistic Animations** - Smooth reload, fire, and movement animations
- **Team System** - Different skins/uniforms for each team
- **Mission-Based** - Players get assigned missions and objectives
- **Dynamic Gameplay** - Win by eliminating the opposing team

### Key Mechanics
✅ Player Controller with smooth movement
✅ Gun System with reload animations
✅ Team-based spawning system
✅ Mission/Objective system
✅ Factory map with dynamic elements
✅ Player customization (temporary names per match)
✅ Audio and visual effects
✅ Matchmaking system

### Tech Stack
- **Game Engine:** Unity
- **Language:** C#
- **Platform:** PC (Windows/Mac/Linux)
